Learning roadmap

  1. Foundations: Linux commands and permissions, networking basics, Git, container concepts, cloud primitives.
  2. Practitioner: Kubernetes workloads and networking, Docker builds, Terraform state, Ansible idempotency, AWS IAM and VPCs.
  3. Operational depth: systemd, memory and I/O troubleshooting, DNS/TLS, metrics and traces, SLOs and alert design.
  4. Senior and exam readiness: incident leadership, error-budget decisions, failure isolation, capacity trade-offs, and multi-layer debugging.

Progression is a learning path, not a guarantee of certification or job outcomes. Pair quizzes with labs, official documentation, and timed practice exams.
