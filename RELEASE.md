# OpsLab v0.1.0-beta.1

[Open the live app](https://skkc2.github.io/devops-interview-quiz/).

A free, MIT-licensed learning and interview-practice app for DevOps and SRE. No account, API key or backend required.

- Eleven subjects, including Kubernetes, Linux, networking, AWS, Terraform, Docker, Ansible, Git/CI, systems, SRE and observability.
- 1,020 scored questions and 330 self-reviewed interview prompts.
- 330 concepts, 348 command/query guides and 110 worked troubleshooting cases.
- Contextual practice questions, explanations, saved review, timed sessions and interview notes.
- Responsive subject selection, searchable learning libraries and local-only progress storage.

## Release validation

Publication is gated on content/schema validation, deterministic compilation and the browser interaction suite in Chromium, Firefox and WebKit. Coverage includes full question rendering, subject selection, practice/exam/interview behavior, mobile overflow, storage failure and failed content downloads.

This is a public beta. Automated tests do not prove every technical statement, screen-reader experience, browser version or physical device. Command examples are instructional and may need platform/version adaptation. Interview material is original practice content, not claimed employer questions. Browser storage is not a backup or cross-device sync service.

Report a problem with the subject/title, exact wording or reproduction steps, and a primary documentation reference where applicable. Do not include production secrets.
